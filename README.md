# Sarvajit Jonnalagadda — personal website

A standalone personal homepage and writing section. Website files live at the repository root.

## Publish with GitHub Pages

In Settings → Pages, select **Deploy from a branch**, **main**, **/(root)**, then Save.

Address: https://sarvajit-j.github.io/

## Edit the website

- `index.html`: homepage and bio
- `vocabulary.html`: vocabulary-size article
- `assets/style.css`: appearance and responsive layout
- `assets/stories.js`: six original saved story samples
- `assets/article.js`: story tabs and keyboard navigation

No build step, dependencies, custom domain, or backend is needed.
